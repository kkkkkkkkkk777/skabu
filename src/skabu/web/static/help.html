ヘルプ

このページは、各画面が何をする場所かと、ボタンの意味をまとめたものです。むずかしい言葉は、出てきたところで説明します。

進む順

株を買うまでの流れは、上のメニューと同じ順です。1から5まで進めると、試し、決めて、今日の候補を買いまで行けます。6と7は、買う前にやらなくても大丈夫です。8は、気になった銘柄の値段の動きを見る場所です。

意味

  • シミュは、過去の値段で「もし買っていたら、お金がどうなったか」を試す場所です。
  • 戦略は、試して良かったやり方を、これから使うルールとして決める場所です。
  • ランキングは、そのルールで今日の銘柄を点数の高い順に並べる場所です。
  • 日次は、次に買う銘柄と株数を出す場所です。
  • 売買は、その銘柄を注文にする場所です。
  • 検証は、その日の予想を残して、あとから当たったかを見る場所です。
  • モデルは、機械が過去から学んだ結果を見る場所です。
  • チャートは、1つの銘柄の値段の動きを見る場所です。

共通

意味

左上の skabu を押すと、最初の案内に戻ります。下の「株価を同期」は、新しい株価を取り込みます。株価とは、その株がいくらで売買されたかという記録です。

ランキング、日次、検証、売買で銘柄の名前を押すと、チャートは別のタブで開きます。同じ名前のタブを使い回すので、銘柄を開くたびにタブが増え続けません。チャートの画面で銘柄を検索したときは、今のタブのまま切り替わります。

使い方

  • 案内に戻るときは、左上の skabu を押します。
  • 株価が古いと感じたら、下の「株価を同期」を押します。
  • メニューの「ヘルプ」は、このページです。チャートの右にあります。

点と門

点は「どれが上か」の順位です。門は「残すか、落とすか」の条件です。ランキングの「買う」は、門を通った銘柄です。点が高くても、門で落ちることがあります。

使い方

シミュ、ランキング、戦略の「点」と「門」から、付ける項目を選びます。項目は意味の近いグループに分かれています。各項目の長い説明は、そのポップの中にもあります。

向き

今の値段が、みんなの目安になる線より上か下かを見ます。上にいる株は、買いが続いていることが多い、という見方です。

  • SMA は、決まった日数の終値の平均です。終値は、その日の最後の値段です。
  • EMA は、SMA に近く、最近の値段をより重くした平均です。
  • Supertrend は、上が続くか下が続くかを、線の上にいるか下にいるかで見ます。
  • 一目均衡は、基準の線と「雲」で、値段が上側か下側かを見ます。

勢い

今、上がる力と下がる力のどちらが強いかを見ます。速く上がりすぎると、あとで戻りやすいこともあります。

  • RSI は 0 から 100 の点数です。高いと上がりすぎ、低いと下がりすぎ、と言われることが多いです。
  • MACD は、短い平均と長い平均の差です。上がる力と下がる力のどちらが強いかを見ます。
  • ADX は、上か下かとは別に、その動きが強いか弱いかを見ます。
  • ストキャスは、今の値段が、最近の高値と安値のどこにいるかを見ます。
  • ATR は、1日にどれくらい動くかの幅です。損切の距離を決めるときに使います。
  • ボリンジャーは、平均の上下に、よくある動きの幅の帯を引きます。
  • 出来高SMA は、売買された株数の平均です。いつもの量より多いかを見ます。
  • 高値モメンタムは、1年の高値に近いか、ここ数か月で上がったかを、ほかの銘柄と比べます。

形

山と谷、または直近のローソクの模様を見ます。よく出る形は、このあと上がるか下がるかのヒントになります。

  • ダブルトップは、高い山が2つ並ぶ形です。下がりやすいと言われます。
  • ダブルボトムは、深い谷が2つ並ぶ形です。上がりやすいと言われます。
  • 切り下げは、高値と安値がだんだん下がっている形です。
  • 切り上げは、高値と安値がだんだん上がっている形です。
  • ヘッドアンドショルダーズは、真ん中がいちばん高い山が3つの形です。下がりやすいと言われます。
  • 逆ヘッドアンドショルダーズは、真ん中がいちばん深い谷が3つの形です。上がりやすいと言われます。
  • ローソク足は、1本ごとの陽線と陰線の模様です。陽線はその日上がった足、陰線は下がった足です。

波

上げと下げを、1、2、3、4、5 の波として数えます。教科書では、上げの3波がいちばん勢いが出やすいとされます。

  • エリオット波動は、今が強い3波の途中か、もう5波が終わったかを数えます。

シミュ

意味

過去の株価で、「このやり方で買っていたら、お金がいくらになっていたか」を試します。本物のお金は動きません。本番は、いま採用しているルールで試します。実験は、この画面だけの点と門で試します。実験にしても、日次と売買のルールは変わりません。

1か月は、選んだ予測日のあと約1か月を見ます。長期は、開始から終了までの長い期間を見ます。資金は最初に持っているお金、銘柄数は同時に何銘柄まで持つか、リスク% は1回の損で資金の何%まで失ってよいか、です。

利確しないにすると、目標の値段で売らず、保有日数の終わりで売ったことにします。利確は、上がったところで利益を確定して売ることです。

使い方

  • 「本番」か「実験」を選びます。実験では版も選べます。版は、点と門をセットにした試しの名前です。
  • 「1か月」か「長期」を選び、日付、資金、銘柄数、リスク% を入れます。
  • 目標で売らない試しは「利確しない」をオンにし、保有日数を入れます。
  • 「実行」で結果が出ます。名前を付けて「この結果を保存」できます。
  • 「保存済み」から「開く」「削除」ができます。「比べる」は、2つの保存した結果を並べます。
  • 下には、買った銘柄の表と、日ごとの残高の線が出ます。

戦略

意味

戦略は、これから日次と売買で使うルールです。採用すると、その点と門が本番になります。作戦の版は、試したルールに付けた名前です。

自動探索は、点と門をまず1つずつ試し、効いた上位を最大3つまで重ねます。選定は候補を探す期間、確認はそれが別の期間でも通用するかを見る期間です。選定で一番でも、確認ではっきり良くなるまで採用しません。

使い方

  • いま採用中の戦略と、試した版の一覧を見ます。
  • 使いたい版を採用します。日次と売買は、このルールを使います。
  • 「自動探索」は、候補を探す長い処理です。終わると、選定と確認の比較が出ます。
  • 「ランキングへ」で、その条件の今日の順位を見られます。
  • 生の口座をオンにする操作は、この画面ではしません。

ランキング

意味

選んだ点と門で、今日の銘柄を点数の高い順に並べます。「買う」は、門を通った銘柄です。市場は、プライム、スタンダード、グロースなど、取引されている場所の区分です。最低出来高は、1日に売買された株数が少なすぎる銘柄を除く条件です。上位は、表に出す件数です。

損切は「ここまで下がったら売る」値段です。目標は「ここまで上がったら当たり」と見る値段です。倍率は、1日の値動きの幅（ATR）の何倍を、その距離にするかです。

使い方

  • 市場、最低出来高、上位、損切の倍率、目標の倍率を変えます。
  • 「再計算」は、その条件で順位を作り直します。時間がかかります。
  • 「採用で見る」は、いま採用中の戦略の点と門で並べます。
  • 気に入った条件は、版の名前を付けて「版として保存」できます。
  • 銘柄を押すと、別のチャートタブで開きます。

日次

意味

採用した戦略で、次に買う銘柄と株数を出します。資金は使えるお金、リスク% は1回の損でその何%まで失ってよいかです。株数は、その損の大きさから計算します。表の終値、金額、損切、目標、RR は、その銘柄を買うときの目安です。RR は、狙う利益が、許容する損の何倍かを示す数字です。

使い方

  • 開くと、最後に出した買う一覧が出ます。
  • 資金とリスク% を変えて「ローカル再出力」を押すと、取り込んである株価で一覧を出し直します。
  • 新しい株価を取り込んで本番の一覧を作る作業は、このボタンとは別です。
  • 「CSV」は、一覧をファイルで保存します。
  • 銘柄を押すと、別のチャートタブで開きます。

売買

意味

日次で出た銘柄を、注文の台帳に載せて買います。ペーパーは、本物のお金を使わない練習の台帳です。承認は、人がOKを押してから買うモードです。自動は、条件がそろったら買うモードです。

損切は逆指値です。逆指値は、「この値段まで下がったら売る」という予約です。目標の値段で売る指値は出しません。保有日数の引けで売ります。引けは、その日の取引の終わりです。売る日が今日の行を選んで「引けで売る」を押します。

使い方

  • 「承認」か「自動」を選びます。保有日数は、何日後の引けで売るかです。
  • 「候補を台帳へ」で、日次の銘柄を待ちの行にします。
  • 行にチェックを付けて「選択を承認」で買います。
  • 「引けで売る」は、選んだ行をその日の終わりで売ります。
  • 「監視更新」は、注文の状態を取り直します。
  • 「緊急停止」は新規の買いを止めます。「再開」で戻します。
  • 下の保有は、いま持っている株の株数、単価、評価、損益です。この表の行からはチャートを開きません。
  • 上の待つ行の銘柄は、別のチャートタブで開きます。

検証

意味

その日に「この銘柄はこうなる」と予測した内容を残し、あとから当たったかを見ます。売買の前に済ませる必要はありません。予測の間隔は、何営業日おきに予測の記録を書くかです。営業日は、市場が開いている日です。

5日と20日は、損切にも目標にも当たらなかったとき、何営業日で売ったことにするかを切り替える表示です。20日は日次と同じ期限です。保存する成績は20日のままです。押し直しても、順位の再計算はしません。

使い方

  • 版、上位、予測の間隔、損切と目標の倍率を選びます。
  • 「5日」か「20日」で、画面に出す期限を切り替えます。
  • 「検証」は成績を計算します。時間がかかります。間隔を変えたあとは、押し直します。
  • 「この結果を保存」で、その予測を残せます。
  • 銘柄を押すと、別のチャートタブで開きます。

モデル

意味

モデルは、目標の値段に損切より先に届く確率を、機械が過去のデータから学んだ結果です。売買の前に見なくても大丈夫です。

  • 当てる対象の比較は、何を正解にして学んだかを比べた数字です。本番の Boost は、ここでは入れ替えません。
  • 運用しながら学習は、日次のあと自動で採点し、条件を満たしたときだけ学び直す記録です。
  • 校正は、機械が出した確率と、実際に当たった割合が近いかです。たとえば 60% と言ったものが、だいたい10回中6回当たっているかを見ます。
  • 採点済み上位の超過は、点が高かった銘柄が、市場全体よりどれだけ良かったかです。
  • 学習履歴は、いつ学んだかの記録です。
  • 特徴量の差は、当たった銘柄と外れた銘柄で、どの材料の数字が違ったかです。

使い方

  • 開くと、学習済みの数字が出ます。未学習の欄は、まだ数字がありません。
  • 「ランキングで使う」から、点を付けた順位表へ行けます。

チャート

意味

1つの銘柄の値段の動きを、ローソク足で見ます。ローソク足の1本は、ある期間の始値、高値、安値、終値です。始値は期間の最初の値段、高値はいちばん高い値段、安値はいちばん安い値段、終値は最後の値段です。

日足は1日を1本、週足は1週間を1本にしたものです。開いたときは、最新の足が右の価格の目盛に張り付かないよう、右に少し余白があります。価格の目盛は、右端のいくら、という数字です。

使い方

  • 上の検索に、銘柄コードか会社名を入れます。例は 8697 やトヨタです。
  • 「日足」と「週足」で、1本の長さを切り替えます。
  • 「インジケーター」で、チャートに線や印を足せます。点と門と同じ項目のうち、チャートに描けるものが入っています。
  • 会社名の横のリンクは、Yahoo!ファイナンスなどの公開チャートを別タブで開きます。
  • シミュから開いたときは、買ってから売った期間に帯が付きます。

描画

描画は、自分で線や箱を足す道具です。ボタンを押すと道具が出ます。もう一度押すか、チャートの外を押すか、Esc で道具は閉じ、移動に戻ります。引いた図は残ります。同じ銘柄の日足と週足は、同じ図を使います。

  • 移動は、チャートをドラッグして見る範囲をずらします。
  • 選択は、引いた線や箱を選んで動かします。端の点をドラッグすると、長さや大きさを変えられます。
  • 線は、2点を結ぶ斜めの線です。選んでいるあいだ「延長」で右へ延ばせます。
  • 水平は、ある値段の横線です。垂直は、ある日付の縦線です。箱は、対角の2点で囲む四角です。
  • 吸着は、クリックした位置を、その足の始値・高値・安値・終値のどれか近い方へ寄せます。最初はオフです。
  • 色は6色から選べます。Delete で選んだ図を消します。Ctrl+Z で直前の操作を取り消します。
  • 図は銘柄ごとに保存されます。ページを閉じても残ります。

意識ポイント

意識ポイントは、多くの人が見ている値段の目安です。押すと一覧が出て、選んだものだけチャートに線を引けます。

  • 押し安値は、上がる前にいったん止まった安い値段です。戻り高値は、下がる前にいったん止まった高い値段です。
  • 20日、60日、52週の高値と安値は、その期間でいちばん高かった値段といちばん安かった値段です。
  • 5日線、25日線、75日線、200日線は、その日数の終値の平均です。
  • 基準線、雲の上、雲の下は、一目均衡の目安です。
  • 前日高値、前日安値、前日終値は、前の営業日の値段です。
  • キリ番は、2100円や2200円のように、人が区切りと見やすい値段です。
